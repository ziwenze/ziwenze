I build practical AI systems and developer tools for workflows that should be easier to use, inspect, and trust.

Currently pursuing an **M.S. in Computer Science at Harbin Institute of Technology**. Previously earned a **B.E. in Software Engineering from Dalian University of Technology**.

My current interests sit at the intersection of **agent-native applications**, **LLM-assisted automation**, and **application security**.

## Selected work

| Project | Description | Focus |
| --- | --- | --- |
| [Seep Reverse Lab](https://github.com/ziwenze/Seep-Reverse-Lab) | Agent-native workbench for multi-platform reverse engineering and CWE-602 authorization audits. | Security / Agents |
| [AI Resume Form Filling Assistant](https://github.com/ziwenze/AI-Resume-Form-Filling-Assistant) | Chrome and Edge extension that combines LLM field mapping with deterministic local form filling. | LLM Apps / Browser |
